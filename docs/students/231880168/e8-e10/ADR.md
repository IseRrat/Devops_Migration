# 决策记录：选择 mixed 风格语义与构建回归测试

日期：2026-11-10。状态：测试方向已由用户指定，测试及采集代码已实现，运行验证待完成。

背景与约束：B 组需要每人完整复现 E8—E10 并提交独立贡献。其他成员分别负责重复 MISSING 去重及 REDUNDANT/macro/共享宏/构建失败/残留 MD 测试；当前分支尚未包含这两份贡献。禁止覆盖他人成果、重写稳定算法或擅自提交和合并。

选择：新增独立临时目录中的 mixed 测试。先确认已知 MD，再核对精确计划、源字节保护、patch 可应用性、变量与宏引用、配方字节保持、重扫无 MD、构建与程序输出。将语义保持与实际执行结果连在同一个回归场景中。

替代方案：修改核心 patch 算法会扩大范围且缺乏本次任务所需依据；重复 macro 或构建失败测试会与组员贡献重叠；只检查 diff 文本不足以证明修复后可构建运行。因此选择测试扩展，暂不修改 lab.py。

代价与覆盖范围：测试需要课程容器内 GCC、Make、Git，较纯文本断言耗时更高；只覆盖给定 mixed profile，不推断共享宏影响已完整解决。失败保护只在本测试确认候选生成不写回，validate() 的接受/拒绝保护由 E10 实验独立验证。
