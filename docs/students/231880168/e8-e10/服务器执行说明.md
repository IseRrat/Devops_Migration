## 运行

```bash
bash labs/e8e10/run_student_leader.sh
```

不要用 `python -O`，实验检查依赖 assert。脚本先检查镜像，再创建唯一的 `work/leader-231880168-XXXXXXXX`。首行 `EVIDENCE=...` 给出真实路径。每次重跑生成新目录，历史目录不删除。内部样例会按手册创建 Git 基线提交；不会提交外层学生仓库。

执行顺序：容器版本 → 原有 ProfileTests → mixed 定向测试 → 全部 profile 测试 → E8 → E9 → E10 → diff 检查。失败立即停止，保留已完成日志和产物。原有 ProfileTests 是在已添加测试的工作区中单独运行，不应描述成“修改前代码已运行通过”。当前发现共 8 个测试，预期运行数量以服务器实际代码为准。
