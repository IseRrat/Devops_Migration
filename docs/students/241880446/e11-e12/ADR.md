# ADR：版本化报告与可追溯输入

编号/日期/作者：B04-241880446-E11E12 / 2026-11-14 / 王佳宝。
问题：报告消费须核对版本、类型与实际文件哈希；服务器默认下载源不稳定。
采用方案：沿用 e11e12-1 envelope、commit、job_id、trace_id、artifact URI/SHA256。保留校验与失败证据，仅在用户批准的新副本中同 SHA256 换源，记录新提交并重新采集报告；不硬改旧报告版本。Debian 超时后更换同发行版站点，保留签名验证。
未采用：放宽基础镜像一致性检查；以课堂样例冒充已有真实开源历史。
项目来源：所给 ZIP 经用户批准建立本地 C0/C1，不另建远程仓库。候选、输入 JSON、来源清单与原始日志随 data/work 归档。
测试与取舍：13 项契约测试、原 13 项回归通过；E11 direct/macro、旧报告拒绝、E12 五阶段、所给项目及本机 API 通过。跨组访问暂未进行。当前公共接口没有修改，无需改变原接口契约。
