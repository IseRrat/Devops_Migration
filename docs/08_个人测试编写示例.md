# 个人测试编写示例：从独立预期到可提交代码

每次实验完成参考路线后，先选择本次实验、本轨道的一例，再完成各实验末尾的自主任务。下面的例子给出完整的测试编写过程；报告记录本人新增的输入、预期和实际结果。

## 1. 找到要修改的文件

**位置**：SSH后的Linux服务器，本人外层课程仓库根目录，个人student/学号/e8-e10分支。

```bash
pwd
git branch --show-current
grep -n '^class\|^if __name__' labs/e8e10/test_profile.py
nano labs/e8e10/test_profile.py
```

**输入**：原有7项测试的test_profile.py。**操作**：在文件底部`if __name__=='__main__':unittest.main()`这一行**前面**，粘贴下面选中的完整类。class这一行顶格；def缩进4个空格，函数体缩进8个空格。保留原有导入、ProfileTests和原7项测试。

**输出**：新增一个Student开头的测试类。nano保存：Ctrl+O、Enter；退出：Ctrl+X。同一类只添加一次。

## 2A. E8 A组：声明变化时复用真实图并重算发现

**输入变化**：只给main.o补config.h声明。**独立预期**：两个对象的真实图复用，MD消除，RD unused.h保留。

```python
class StudentE8A(unittest.TestCase):
    def test_declaration_change_reuses_actual_graph(self):
        with tempfile.TemporaryDirectory() as directory:
            p=Path(directory)/'sample'
            fixture(p)
            old=scan(p)
            f=p/'Makefile'
            f.write_text(f.read_text().replace('main.c unused.h','main.c unused.h config.h'))
            commit(p,'student: add missing declaration')
            result=scan(p,old)
            self.assertEqual(result['actual'],old['actual'])
            self.assertEqual(set(result['reused']),{'main.o','helper.o'})
            self.assertEqual(result['refreshed'],[])
            self.assertEqual(
                {(x['type'],x['target'],x['dependency']) for x in result['findings']},
                {('REDUNDANT','main.o','unused.h')})
```

**通过条件**：新增测试通过；如果只复用旧findings，这个测试会发现仍残留MD的错误。

## 2B. E8 B组：生成补丁时保留原编译配方

**输入**：未修复项目的同版本报告。**独立预期**：Patch只修改目标依赖；应用到临时样例后，所有TAB开头的配方行保持原字节。

```python
class StudentE8B(unittest.TestCase):
    def test_patch_keeps_recipe_bytes(self):
        from lab import run
        with tempfile.TemporaryDirectory() as directory:
            p=Path(directory)/'sample'
            fixture(p)
            before=(p/'Makefile').read_bytes()
            diff,plan=patch(p,scan(p))
            candidate=Path(directory)/'candidate.patch'
            candidate.write_text(diff)
            run(['git','apply',str(candidate.resolve())],p)
            after=(p/'Makefile').read_bytes()
            recipes=lambda data:[line for line in data.splitlines() if line.startswith(b'\t')]
            self.assertEqual(recipes(before),recipes(after))
            self.assertIn(b'main.o: main.c unused.h config.h',after)
            self.assertEqual(plan[0]['style'],'direct')
```

**通过条件**：依赖补齐、配方逐行相同；临时目录结束时自动清理，不修改手册OUT中的项目。

## 2C. E9 A组：头文件中的新include使缓存失效

**输入变化**：config.h新增对extra.h的包含。**独立预期**：main.o真实依赖为三个项目文件，新增MD extra.h，两个目标保守刷新。

```python
class StudentE9A(unittest.TestCase):
    def test_include_inside_header_invalidates(self):
        with tempfile.TemporaryDirectory() as directory:
            p=Path(directory)/'sample'
            fixture(p)
            old=scan(p)
            (p/'config.h').write_text('#include "extra.h"\n#define VALUE 1\n')
            commit(p,'student: header includes extra')
            result=scan(p,old)
            self.assertEqual(result['actual']['main.o'],['config.h','extra.h','main.c'])
            self.assertIn(['MISSING','main.o','extra.h'],result['added'])
            self.assertEqual(set(result['refreshed']),{'main.o','helper.o'})
```

**通过条件**：检测到间接include；只检查main.c而漏看头文件预处理变化的实现会失败。

## 2D. E9 B组：变量风格的补丁修改变量定义

**输入**：main.o依赖`$(DEPS)`。**独立预期**：DEPS新增config.h，目标行保留变量引用，重检无MD。

```python
class StudentE9B(unittest.TestCase):
    def test_macro_style_patch_updates_definition(self):
        from lab import run
        with tempfile.TemporaryDirectory() as directory:
            p=Path(directory)/'sample'
            fixture(p,'macro')
            diff,plan=patch(p,scan(p))
            candidate=Path(directory)/'candidate.patch'
            candidate.write_text(diff)
            run(['git','apply',str(candidate.resolve())],p)
            text=(p/'Makefile').read_text()
            self.assertIn('DEPS = main.c unused.h config.h',text)
            self.assertIn('main.o: $(DEPS)',text)
            self.assertEqual(plan[0]['style'],'macro')
            self.assertFalse(any(x['type']=='MISSING' for x in scan(p)['findings']))
```

**通过条件**：变量定义和目标引用都符合预期；重检确认补丁确实改变声明关系。

## 2E. E10 A组：间接include的增量/全量集合一致

**输入变化**：config.h包含extra.h，extra.h再包含leaf.h。**独立预期**：main.o依赖main.c/config.h/extra.h/leaf.h，MD集合含三个头文件；增量与全量三类集合完全一致。

```python
class StudentE10A(unittest.TestCase):
    def test_transitive_include_matches_full_scan(self):
        with tempfile.TemporaryDirectory() as directory:
            p=Path(directory)/'sample'
            fixture(p)
            old=scan(p)
            (p/'config.h').write_text('#include "extra.h"\n#define VALUE 1\n')
            (p/'extra.h').write_text('#include "leaf.h"\n')
            (p/'leaf.h').write_text('#define LEAF 7\n')
            commit(p,'student: transitive include')
            incremental=scan(p,old)
            full=scan(p)
            for key in ['actual','declared','findings']:
                self.assertEqual(incremental[key],full[key])
            self.assertEqual(incremental['actual']['main.o'],['config.h','extra.h','leaf.h','main.c'])
            missing={x['dependency'] for x in incremental['findings'] if x['type']=='MISSING'}
            self.assertEqual(missing,{'config.h','extra.h','leaf.h'})
```

**通过条件**：集合比较与独立边集断言同时通过。自主性能任务可用这个输入再测五次，保存实际计时。

## 2F. E10 B组：编译失败时拒绝且保留源Makefile

**输入变化**：候选Patch仍能应用，但main.c故意加入不合法的C语句。**独立预期**：patch_applies=True，build没有成功标记，error记录编译命令失败，accepted=False；源Makefile逐字节保持。

```python
class StudentE10B(unittest.TestCase):
    def test_build_failure_keeps_original_makefile(self):
        from lab import validate
        with tempfile.TemporaryDirectory() as directory:
            root=Path(directory)
            p=root/'sample'
            fixture(p)
            diff,plan=patch(p,scan(p))
            candidate=root/'candidate.patch'
            candidate.write_text(diff)
            before=(p/'Makefile').read_bytes()
            (p/'main.c').write_text('this is invalid C;\n')
            result=validate(p,candidate,root/'validation')
            self.assertTrue(result['checks']['patch_applies'])
            self.assertFalse(result['checks'].get('build',False))
            self.assertIn('COMMAND_FAILED',result['error'])
            self.assertFalse(result['accepted'])
            self.assertTrue(result['rollback'])
            self.assertTrue(result['source_unchanged'])
            self.assertEqual((p/'Makefile').read_bytes(),before)
```

**通过条件**：故意编译失败的候选被拒绝，测试本身为通过。它补充手册中“测试失败”和“Patch不能应用”的两种拒绝原因。
