Git状态会显示大量旧文件删除，这是只保留实验的预期变化。原来已跟踪的证据迁移后匹配work忽略规则，需精确白名单补充，不可遗漏：

```bash

git diff --check
git add -A
git add -f --pathspec-from-file=docs/原跟踪实验文件新路径.txt

git diff --cached --summary
```
