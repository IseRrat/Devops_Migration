# E8 B组逐步实操：固定MD报告与候选补丁

适用人群：教师示范和本轨道学生。每个代码框按顺序完整复制，框内的PY结束标记也要复制。服务器提示符root@...#或$不属于命令。当前实验独立创建样例，不覆盖之前的OUT。

**本次目标**：理解MD输入、提交身份、目标定位与候选Patch，观察旧报告被拒绝。

**开始条件**：先完整完成[公共准备](00_公共准备.md)的学生路线，原GitHub仓库已包含run_lab.py、labs/e8e10/lab.py，环境镜像已构建。电脑浏览器只用于GitHub；下方命令均在SSH连接后的Linux服务器、本人仓库根目录执行。

**推荐课堂路线**：教师先按PPT讲输入和判断，再逐步运行本页；学生跟做并保存自己的OUT。PPT中的`python3 run_lab.py e8 --track B --out ...`是同一核心函数的一键演示入口。本手册采用拆分操作路线，完成后不必再对相同状态重复运行一键入口。

## 4. 检查报告身份

**要做什么/为什么**：避免使用其他提交的发现改当前文件。

**输入**：报告commit与内部Git HEAD。

```bash
lab_python "$OUT" <<'PY'
from pathlib import Path
import json,sys
from lab import run
out=Path(sys.argv[1]);r=json.loads((out/'fixed-md-report.json').read_text())
sha=run(['git','rev-parse','HEAD'],out/'project').strip()
assert r['commit']==sha
print('COMMIT_MATCH',sha)
print('MD',[f for f in r['findings'] if f['type']=='MISSING'])
PY
```

**输出与保存位置**：终端打印COMMIT_MATCH和需要修复的MD条目。

**通过条件/预期**：commit相同，唯一MD为main.o/config.h。

**失败处理**：本步出现Traceback或STEP_EXIT_CODE非0时停止；先按报错处理，再用新OUT从本实验开始重做，原证据保留。

## 5. 定位并生成Git Patch

**要做什么/为什么**：只处理MISSING，在显式main.o依赖列表增加config.h。

**输入**：同版本报告、当前Makefile和config.h。

```bash
lab_python "$OUT" <<'PY'
from pathlib import Path
import json,sys
from lab import patch,save
out=Path(sys.argv[1]);r=json.loads((out/'fixed-md-report.json').read_text())
diff,edits=patch(out/'project',r)
(out/'candidate.patch').write_text(diff);save(out/'patch-plan.json',edits)
assert '+main.o: main.c unused.h config.h' in diff
assert (out/'project/Makefile').read_text().find('config.h')<0
print(diff);print(edits);print('PATCH_GENERATED_SOURCE_UNCHANGED')
PY
```

**输出与保存位置**：candidate.patch、patch-plan.json。

**通过条件/预期**：PATCH_GENERATED_SOURCE_UNCHANGED；计划style=direct；没有删除unused.h或改编译命令。

**失败处理**：本步出现Traceback或STEP_EXIT_CODE非0时停止；先按报错处理，再用新OUT从本实验开始重做，原证据保留。

## 7. 制造旧报告并观察拒绝

**要做什么/为什么**：主动验证身份前置检查，而不是等错误补丁进入构建。

**输入**：正确报告的副本，把commit改为不匹配值。

```bash
lab_python "$OUT" <<'PY'
from pathlib import Path
import json,sys
from lab import patch,save
out=Path(sys.argv[1]);r=json.loads((out/'fixed-md-report.json').read_text());r['commit']='0'*40
before=(out/'project/Makefile').read_bytes()
try:
    patch(out/'project',r)
except ValueError as error:
    assert str(error)=='STALE_REPORT'
    save(out/'expected-failure.json',{'error':str(error)})
    print('EXPECTED_REJECTION',error)
else:
    raise AssertionError('旧报告未被拒绝')
assert before==(out/'project/Makefile').read_bytes()
print('SOURCE_BYTES_UNCHANGED')
PY
```

**输出与保存位置**：expected-failure.json、步骤日志。

**通过条件/预期**：EXPECTED_REJECTION STALE_REPORT、SOURCE_BYTES_UNCHANGED。内部拒绝符合预期，本步STEP_EXIT_CODE=0。

**失败处理**：本步出现Traceback或STEP_EXIT_CODE非0时停止；先按报错处理，再用新OUT从本实验开始重做，原证据保留。
