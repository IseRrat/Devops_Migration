# E9 B组逐步实操：逐种声明风格生成补丁

适用人群：教师示范和本轨道学生。每个代码框按顺序完整复制，框内的PY结束标记也要复制。服务器提示符root@...#或$不属于命令。当前实验独立创建样例，不覆盖之前的OUT。

**本次目标**：在独立项目中观察direct/macro/mixed的原始声明、修改位置、Git Patch和源文件保护。

**开始条件**：先完整完成[公共准备](00_公共准备.md)的学生路线，原GitHub仓库已包含run_lab.py、labs/e8e10/lab.py，环境镜像已构建。电脑浏览器只用于GitHub；下方命令均在SSH连接后的Linux服务器、本人仓库根目录执行。

**推荐课堂路线**：教师先按PPT讲输入和判断，再逐步运行本页；学生跟做并保存自己的OUT。PPT中的`python3 run_lab.py e9 --track B --out ...`是同一核心函数的一键演示入口。本手册采用拆分操作路线，完成后不必再对相同状态重复运行一键入口。

## 1. 创建并修复直接枚举风格

**要做什么/为什么**：同一个MD在不同声明结构中选择不同的增补位置。

**输入**：当前风格的新项目与scan生成的固定报告。

```bash
lab_python "$OUT" <<'PY'
from pathlib import Path
import sys
from lab import fixture,scan,patch,save,run
out=Path(sys.argv[1]);p=out/'direct'
fixture(p,'direct');report=scan(p);save(out/'direct-input.json',report)
before=(p/'Makefile').read_bytes();diff,edits=patch(p,report)
(out/'direct.patch').write_text(diff);save(out/'direct-plan.json',edits)
assert edits[0]['style']=='direct'
assert before==(p/'Makefile').read_bytes()
print('INPUT MAKEFILE\n'+before.decode());print('PATCH\n'+diff)
print('PLAN',edits)
print(run(['git','apply','--check',str((out/'direct.patch').resolve())],p))
print('STYLE_PASS','direct')
PY
```

**输出与保存位置**：$OUT/direct/项目、direct-input.json、direct.patch、direct-plan.json。

**通过条件/预期**：main.o依赖行增加config.h，style=direct。 原文件保持原字节；应用检查通过。

**失败处理**：本步出现Traceback或STEP_EXIT_CODE非0时停止；先按报错处理，再用新OUT从本实验开始重做，原证据保留。

**教师讲解/学生应能回答**：Patch是候选产物，git apply --check成功只表示可以应用；是否构建和测试正确放到E10判断。
