# E10 B组逐步实操：候选验证、接受与失败回滚

适用人群：教师示范和本轨道学生。每个代码框按顺序完整复制，框内的PY结束标记也要复制。服务器提示符root@...#或$不属于命令。当前实验独立创建样例，不覆盖之前的OUT。

**本次目标**：把Patch生成和接受分开，逐次运行错误测试拒绝、正常接受和坏Patch拒绝。

**开始条件**：先完整完成[公共准备](00_公共准备.md)的学生路线，原GitHub仓库已包含run_lab.py、labs/e8e10/lab.py，环境镜像已构建。电脑浏览器只用于GitHub；下方命令均在SSH连接后的Linux服务器、本人仓库根目录执行。

**推荐课堂路线**：教师先按PPT讲输入和判断，再逐步运行本页；学生跟做并保存自己的OUT。PPT中的`python3 run_lab.py e10 --track B --out ...`是同一核心函数的一键演示入口。本手册采用拆分操作路线，完成后不必再对相同状态重复运行一键入口。

## 3. 准备固定MD与候选

## 4. 故意设置错误测试预期并验证拒绝

**要做什么/为什么**：同一个可应用补丁，在功能测试不满足时不得写回源目录。

**输入**：原项目、候选、fail_test=True（预期99，实际1）。

```bash
lab_python "$OUT" <<'PY'
from pathlib import Path
import sys
from lab import validate
out=Path(sys.argv[1]);p=out/'project';before=p.joinpath('Makefile').read_bytes()
r=validate(p,out/'candidate.patch',out/'reject-test',fail_test=True)
assert r['accepted'] is False and r['checks']['test'] is False
assert r['rollback'] is True and r['source_unchanged'] is True
assert p.joinpath('Makefile').read_bytes()==before==(out/'source-before.Makefile').read_bytes()
print('EXPECTED_TEST_REJECTION',r)
PY
```

**输出与保存位置**：reject-test/validation.json、sandbox、build.log、incremental.log、recheck.json。

**通过条件/预期**：accepted=False、checks.test=False、rollback=True、source_unchanged=True；STEP_EXIT_CODE=0表示拒绝案例达到预期。

**失败处理**：本步出现Traceback或STEP_EXIT_CODE非0时停止；先按报错处理，再用新OUT从本实验开始重做，原证据保留。

## 8. 制造无效Patch，证明已接受版本仍受保护

**输入**：当前已接受Makefile，内容为invalid patch的新候选。

```bash

PY
```

**输出与保存位置**：broken.patch、source-after-accept.Makefile、reject-patch/validation.json。

**通过条件/预期**：error中有git apply失败原因，rollback=True、source_unchanged=True；保存的是已接受后的源字节。

## 9. 执行真实BuildChecker重检并生成阶段汇总

**要做什么/为什么**：最终受测项目确实消除了MD，三种质量判定都符合预期。

**输入**：最终project、三个validation.json。

```bash
lab_python "$OUT" <<'PY'
from pathlib import Path
import csv,json,sys
from lab import buildchecker,save
out=Path(sys.argv[1]);buildchecker(out/'project',out/'recheck-buildchecker')
report=json.loads((out/'recheck-buildchecker/findings.json').read_text())
assert not any(f['type']=='MISSING' for f in report['findings'])
rows=[]
for case,directory in [('test-rejection','reject-test'),('accepted','accept'),('patch-rejection','reject-patch')]:
 r=json.loads((out/directory/'validation.json').read_text())
 passed=r['accepted'] if case=='accepted' else r['rollback'] and r['source_unchanged'] and not r['accepted']
 assert passed;rows.append({'case':case,'passed':passed})
with (out/'results.csv').open('w',newline='') as f:
 w=csv.DictWriter(f,fieldnames=['case','passed']);w.writeheader();w.writerows(rows)
save(out/'gate.json',{'track':'B','passed':True,'rows':len(rows)})
print('B_GATE_PASS',rows)
PY
```

**输出与保存位置**：results.csv、gate.json、recheck-buildchecker原始动态证据。

**通过条件/预期**：三行passed=True、rows=3、真实BuildChecker无MISSING。

**失败处理**：本步出现Traceback或STEP_EXIT_CODE非0时停止；先按报错处理，再用新OUT从本实验开始重做，原证据保留。
