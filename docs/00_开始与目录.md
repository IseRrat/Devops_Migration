# B组E5–E7：开始与目录

目标：复现DRAFT教学样例的构建失败，保存有来源的修复候选，自动完成两轮构建与程序验证，再通过故障测试、CI和合并门禁验收。本分支仅保留B组内容。

## 1. 阶段任务

|阶段|B组任务|提交内容|
|---|---|---|
|E5：复现|真实缺make失败、比较两类提示、保存候选及原始回复|原始输入、日志、退出码、候选来源|
|E6：核心能力|初始构建、候选构建、同镜像ID禁网运行验证|两轮Dockerfile、哈希、报告、镜像ID与输出|
|E7：验证|完整服务测试及五故障/成功场景，CI、失败禁止合并及修复恢复|gate JSON/CSV、日志、保护/拒绝/恢复/合并证据|

## 3. 操作约定

- 在自己的克隆工作目录执行，Git身份使用本人学号。
- 从仓库根运行`cd labs/B-draft`后执行构建/gate；每次使用新work输出目录。
- 保留E5/E6原件及作者归属，不用历史成果冒充本人的新运行。
- 使用`--candidate fixtures/ci-candidates/e6-241830086/Dockerfile`复用有来源的E6候选；不是新模型生成，也不是包内DeepSeek候选。
- 正常交付分支不放故意失败测试；演示必须先失败、保存普通合并拒绝、再修复。
- 报告填写真实退出码、状态、证据路径与提交SHA。没有执行或未提供的记录保持待核实。
